# FCU Shared UI Base Components

This directory contains base UI primitives styled with FOCUS Uganda / FCU brand tokens.

## Brand Tokens
- **Primary:** `#F4B400` (`bg-primary`, `text-primary`)
- **Background:** `#FFFBEA` (`bg-background`)
- **Soft Accent:** `#FFF3C4` (`bg-primary-soft`)
- **Accent:** `#FDE68A` (`bg-accent`)
- **Border:** `#E6D48A` (`border-border`)
- **Foreground:** `#111111` (`text-foreground`)
- **Muted Text:** `#6A6A6A` (`text-muted`)
- **Typography:** Source Sans 3 (`font-sans`)

## Accessibility Standards
- Minimum 4.5:1 contrast ratio against yellow and white surfaces
- Focus visible indicators (`focus-visible:ring-2 focus-visible:ring-primary focus-visible:outline-none`)
- Accessible ARIA roles for dialogs, tabs, progress bars, and alert notices
- Keyboard navigation (Esc key to dismiss panels, Tab key traversal, Skip to content link)
- 1024px desktop-first layout with responsive tablet collapse
