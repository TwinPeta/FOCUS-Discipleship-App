# FOCUS-Discipleship-App
A one stop centre for students, believers in the Christian Faith.

## Monorepo Structure

- **`backoffice/`**: Next.js 15 backoffice web application for staff (system admins, content admins, super-mentors).
- **`mobile/`**: Flutter mobile client application for students and community members.
- **`backend/`**: Node.js backend API services.
- **`docs/`**: Shared specifications, schemas, and design documents.
